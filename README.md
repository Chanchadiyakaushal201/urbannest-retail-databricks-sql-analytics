# UrbanNest Retail Analytics with Databricks SQL

## Overview

UrbanNest Retail Analytics is an enterprise-scale retail analytics project built using Databricks SQL, Databricks Dashboards, AI Genie, and Power BI.

The project uses a clean Gold-layer star schema to analyze one million retail sales transactions between 2021 and 2025.

## Technologies

- Databricks SQL
- SQL
- Databricks Dashboards
- AI Genie
- Power BI

## Dataset

- 100,000 Customers
- 5,000 Products
- 1,000,000 Sales Records
- Business-ready Gold Layer
